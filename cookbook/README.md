# Cookbook

Worked end-to-end examples for common Salesforce DevOps scenarios. Each one is a recipe you can adapt.

## Examples

| Example | What it covers |
|---------|----------------|
| 01 - Setting up a 2GP unlocked package | From greenfield project to first installable version |
| 02 - GitHub Actions PR pipeline | Validate, test, scratch org cleanup |
| 03 - Sandbox refresh runbook | Full sandbox refresh with anonymisation script |
| 04 - Production deploy with validate-then-quick | Reference pattern for production cut-overs |

Each example has its own folder with all the files needed.

## How to use

1. Copy the example folder.
2. Read the example's README.
3. Replace placeholders with your project's values.
4. Adapt to your CI provider, branching strategy, etc.

These are not turnkey solutions. They are starting points.
