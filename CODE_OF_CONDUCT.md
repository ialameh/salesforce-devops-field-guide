# Code of Conduct

This project follows the spirit of the Contributor Covenant.

## Our pledge

We commit to making participation in this project a respectful experience for everyone.

## What we expect

- Be kind. Disagree about content, not about people.
- Stay on topic. This project is Salesforce DevOps documentation.
- Be patient. People come to this guide at different levels of experience.
- Give credit. When someone contributes an idea, fix, or example, name them.

## What is not okay

- Harassment, discrimination, or personal attacks.
- Trolling, deliberate provocation, bad-faith argument.
- Sharing private information without permission.
- Sustained disruption.

## How issues are handled

If someone violates the code of conduct, maintainers will:

1. Privately ask the person to stop and explain why.
2. If the behaviour continues, issue a public warning.
3. If still continuing, ban from the project.

## Reporting

Contact the maintainers privately. Do not name the person publicly until maintainers have investigated.
