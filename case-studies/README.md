# Case Studies

Anonymised real Salesforce DevOps incidents and how they were resolved. Each one follows the same structure: what broke, initial hypothesis, root cause, what was done, lessons.

## Cases

This folder is a place for real incidents to land as they happen. Contributions welcome (see [CONTRIBUTING.md](../CONTRIBUTING.md)).

## Format

Each case study has:

1. **Context.** What was the team building? Environment specifics.
2. **Symptoms.** What did people see?
3. **Initial hypothesis.** What did they think was wrong?
4. **What was actually wrong.** With diagnosis.
5. **What they did.** Step by step.
6. **What they learned.** Takeaways.

Anonymise everything. No real org names, customer names, employee names, or project codenames. Use generic stand-ins.
